📖 Como Funciona a Integração WAHA + Chatwoot + Gemini

1. Fluxo de Atendimento Automático

  • O cliente envia mensagem no WhatsApp. A WAHA recebe e despacha para o Chatwoot (inbox de atendimento) e simultaneamente envia o webhook para o BotZap.
  • O BotZap aplica o buffer anti-mensagens picadas (debounce), carrega o histórico e chama o Gemini Flash.
  • O bot envia a resposta para a WAHA via POST /api/sendText. A mensagem vai para o cliente e aparece no Chatwoot!

2. Transbordo Humano Inteligente

  • Se o cliente disser "quero falar com uma pessoa", o HandoffAgent envia mensagem de aviso e pausa o bot para aquele número.
  • Se um atendente humano digitar diretamente no Chatwoot ou no celular do WhatsApp, a WAHA envia um evento com fromMe: true. O BotZap detecta automaticamente e pausa o bot por 60 minutos para não atrapalhar o atendente!

3. Configuração de Variáveis na WAHA (Docker)

# No arquivo docker-compose da WAHA:
WHATSAPP_HOOK_URL=http://botzap:3001/webhook/waha
WHATSAPP_HOOK_EVENTS=message
